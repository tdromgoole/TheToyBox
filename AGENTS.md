# Project Instructions

## Wrap Up Command

When the user says **"wrap up"**, complete these release-preparation steps:

1. Choose and update the version using semantic versioning. Keep `package.json` and `package-lock.json` synchronized.
2. Review the extension categories and keywords, updating them only when the completed changes warrant it.
3. Update `README.md` with high-level, user-focused descriptions. Avoid unnecessary implementation details.
4. Update `CHANGELOG.md` with the completed changes under the new version and release date.
5. Run the relevant compilation, lint, test, and production-package checks.
6. Summarize the release version, metadata decisions, changed release files, and validation results.
7. Finish by providing a ready-to-use commit message that reflects all changes included in the release.
